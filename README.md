# BOOMRANG (No texture and 3d model warning)

This is a simple minecraft mod made with pure rage caused by my other hardware stuffs that I have been making, on top of that frustration due to compitative exams

This mod feature 5 boomerang and requires ## Version 26.1.2
1. Simple boomerang
2. TNT boomerang
3. Ender Boomerang
4. Fire Boomerang
5. Ice Boomerang
   And to play this mod download "boomrang-1.0.0-26.1.2.jar" from this repo
